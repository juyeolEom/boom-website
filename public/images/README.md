# BOOM Lab image slots

Replace these files while keeping the filenames unchanged:

- `boom-hero.png` — homepage hero, wide landscape (recommended 2400 × 1200 or larger)
- `research-microscopy.png` — research card, landscape (recommended 1600 × 1000)
- `research-light-sheet.png` — research card, landscape (recommended 1600 × 1000)

The page crops images automatically with `object-fit: cover`, so photos with the main subject near the center work best.
